# Musical Genius

A party game for a TV and a room full of phones. Everyone nominates songs, the TV
plays them one after another, phones vote as each song plays, and after the set
number of rounds the crowd's favourite wins.

- **Web**: the host opens the app on the TV's browser; guests can join from any phone browser.
- **iOS / Android**: the guest controller, built with Capacitor.

See `CLAUDE.md` for commands and setup.
